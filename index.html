브랜치 시작하기

STEP BY STEP

브랜치 연습 순서

01

브랜치 생성

새 기능을 작업할 브랜치를 생성합니다.

git switch -c feature/header
02

파일 수정

헤더의 로고나 메뉴 내용을 변경합니다.

git add .
03

커밋 저장

수정한 내용을 하나의 작업 기록으로 남깁니다.

git commit -m "header 수정"
04

브랜치 병합

main 브랜치로 이동한 뒤 작업 내용을 합칩니다.

git merge feature/header
